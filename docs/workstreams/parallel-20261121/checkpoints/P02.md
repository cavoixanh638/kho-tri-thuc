## Format choice and scope

1. CommonMark inline links are the portable baseline; internal app links `#/muc/<UUID>` are rewritten to relative encoded Markdown file paths on export and restored via the manifest on import. Code fences/inline code are untouched; unsupported nested Markdown constructs are not promised lossless.
2. Obsidian's `[[wiki links]]` and YAML/frontmatter plugin conventions require third-party-specific parsing and ambiguous-name resolution; **not** accepted for import. Only this project's versioned JSON-valued frontmatter ZIP is supported.
3. Other Markdown editors can read/edit individual `.md` files; editing a Markdown body marks `edited_markdown` for explicit import approval. Unknown manifest versions/entries and unresolved references are rejected, not silently mapped.
4. ZIP contains no media bytes, StorageLocation/Drive IDs, signed URLs, OAuth tokens, source credential query parameters, or application secrets. **It is not a full DB backup or Drive restore**. Source URL/raw note data is potentially sensitive by nature; the user must handle the ZIP accordingly.
