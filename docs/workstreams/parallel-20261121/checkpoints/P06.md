## Assumptions and limitations
- Source citation is **provenance evidence**, not an inferred semantic assertion that a specific authored sentence is proven by a specific paragraph.
- Authored note is the authoritative Markdown; extracted raw content is presented only as independent evidence, never written back into `Item.note`.
- Legacy `Knowledge` API response shape is preserved (new behavior for authored `parts`); no shared API schema file modification.
- The backend retains existing caps of 1000 parts and 100k extract characters, and a truncated flag; not a complete unlimited 10k evidence browser.
- Linked but foreign assets/sources remain flagged missing, not navigable; source URLs do not include provider secret IDs. The host must still enforce authentication for viewer bytes.
- PDF `#page` navigation requires actual browser PDF viewer support, not established by the JSDOM fixture.
- The feature is coded and pushed, **not claimed fully accepted or deployed**.
